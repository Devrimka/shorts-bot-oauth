Privacy Policy

Last updated: 2026-09-21

DevrimKa Shorts Bot is a personal, single-user automation tool. It is not a public-facing service, does not have external users, and does not collect or process personal data from anyone other than its own owner.

What this application accesses

The application uses Google OAuth2 to authenticate as its owner's own YouTube channel, using the following YouTube Data API scopes:

  • youtube.upload — to upload videos to the owner's channel.
  • youtube — to manage the owner's own playlists.
  • youtube.force-ssl — to post comments as the channel owner on the owner's own uploaded videos.

All of these actions are performed on the application owner's own YouTube channel only. The application does not read, access, or act on any other user's YouTube account, videos, or data.

What this application does not do

  • It does not collect personal data from any third party.
  • It does not share, sell, or transmit any data to any other service or party.
  • It has no public sign-up, login, or user accounts of its own.

Data storage

The OAuth credentials issued to this application are stored locally on the owner's own machine and are used only to authenticate the automated publishing pipeline described on the home page.

Contact

Questions about this application can be directed to the channel owner via the DevrimKa YouTube channel.
